# 첨부 이미지 기반 홈페이지 색감 및 배너 개편 작업

## 작업 목적

현재 홈페이지의 문구와 모든 기능은 그대로 유지하면서, 첨부 이미지의 밝고 차분한 화이트·페리윙클 블루 색감과 펼쳐진 책 이미지를 홈페이지 주요 시각 영역에 반영한다.

이 작업은 디자인 변경만을 목적으로 한다. 추천 로직, 계정, 즐겨찾기, 랭킹, 관리자, 무료 전자책 링크, API, 저장소 및 배포 설정 등 기존 기능은 변경하지 않는다.

- 원본 경로: `C:\Users\ADMIN\Downloads\ChatGPT Image 2026년 9월 1일 오후 08_55_37.png`
- 원본 크기: `2004 x 785`
- 프로젝트 경로: `C:\CLI\18.구미도시공사 AI북큐레이터`
- 이미지 평가: 기존 짙은 청록 배너보다 밝고 정돈된 인상이며, 실제 책 형태가 중심이라 서비스 주제 전달이 좋다. 투명 구체와 작은 장식은 메인 배너에서만 절제해 사용하고 다른 영역에는 반복하지 않는다.

## 가장 중요한 원칙

1. 첨부 이미지 안에 포함된 문구는 사용하지 않는다.
2. 홈페이지 문구는 작업 시작 시점의 `public/index.html` 내용을 글자 하나까지 그대로 유지한다.
3. 첨부 이미지에서는 전체적인 색감, 빛, 질감과 오른쪽의 펼쳐진 책 이미지만 활용한다.
4. 배너 문구는 이미지에 합치지 않고 기존 HTML 텍스트로 유지한다.
5. 디자인 이외의 기능과 동작은 그대로 보존한다.
6. 기존 작업물이 있는 더러운 Git 작업 트리를 전제로 한다. `git reset --hard`, `git checkout --`, 파일 전체 덮어쓰기 등 다른 변경을 되돌리는 명령은 사용하지 않는다.
7. 사용자의 화면 확인과 승인을 받기 전에는 운영 배포하지 않는다.

## 작업 전 롤백 준비

1. `git status --short`로 기존 변경 상태를 기록한다.
2. 수정할 파일만 작업 폴더 밖의 버전별 백업 폴더에 복사한다.
   - 권장 위치: `C:\CLI\output\ai-book-curator-theme-backup-YYYYMMDD-HHMMSS`
   - 최소 백업 대상: `public/index.html`, `public/styles.css`, 새로 교체할 이미지 자산
3. 다른 수정 파일은 건드리지 않는다.
4. 마지막으로 확인된 첫 이미지 스타일 운영 배포 버전은 `6aac6515-a2f3-45d1-be36-bde16ff918c9`이다.
5. 롤백이 필요하면 백업한 디자인 파일만 복원한 뒤 반드시 `npm run deploy`로 재배포한다.

## 디자인 방향

- 배경: 거의 흰색에 가까운 쿨 화이트에서 옅은 블루로 이어지는 부드러운 그라데이션
- 주조색: 페리윙클 블루, 코발트 블루, 옅은 라벤더 블루
- 본문색: 푸른 기가 약간 있는 짙은 네이비
- 보조색: 쿨 그레이와 저채도 블루
- 질감: 밝고 깨끗하며 공기감 있는 스튜디오 조명
- 그림자: 진한 검정 그림자 대신 넓고 부드러운 블루 계열 그림자
- 장식: 구체, 궤도, 작은 사각 프레임은 메인 배너에서만 최소한으로 사용
- 피해야 할 표현: 과한 네온, 진한 청록 단색 화면, 여러 영역에 반복되는 구체 장식, 낮은 대비, 흐릿한 본문, 과도한 광택

색상은 첨부 이미지에서 실제로 추출해 CSS 변수로 정리한다. 시작 후보는 아래와 같으며 최종값은 화면 비교 후 조정한다.

```css
:root {
  --theme-bg: #f6f8ff;
  --theme-bg-blue: #dce7f8;
  --theme-primary: #5f78e8;
  --theme-primary-strong: #3f5fd4;
  --theme-ink: #20283a;
  --theme-muted: #616b7d;
  --theme-line: #d7e0f0;
  --theme-surface: #ffffff;
}
```

## 적용 범위

### 1. 홈페이지 전체 배너

- 현재 헤드라인, 설명, 메타 문구는 그대로 둔다.
- 첨부 이미지의 오른쪽 책 부분을 별도 배너 자산으로 사용한다.
- 원본 이미지 전체를 그대로 배경으로 넣지 않는다. 왼쪽에 다른 문구가 이미 들어 있기 때문이다.
- 실행 방법은 다음 중 품질이 가장 좋은 방식을 선택한다.
  - 오른쪽 책 부분을 고품질로 분리 또는 크롭해 별도 WebP/PNG 자산으로 제작한다.
  - 필요하면 이미지 편집으로 기존 문구 영역을 제거한 배경 전용 버전을 만든다.
- HTML 문구가 이미지 위에서 충분한 대비를 갖도록 왼쪽에는 밝은 단색 또는 미세한 그라데이션 영역을 확보한다.
- 데스크톱에서는 펼쳐진 책이 우측 핵심 시각 요소가 되게 한다.
- 모바일에서는 책이 본문을 가리지 않도록 우측 하단으로 축소하거나 배경 장식 수준으로 처리한다.
- 배너 이미지는 `public` 아래에 의미 있는 버전 파일명으로 저장한다. 기존 자산을 덮어쓰지 않는다.

### 2. `무료로 읽기` 영역

- 우측 `BOOK LINKS / 무료로 읽기` 탭과 펼쳐지는 패널의 짙은 청록을 첨부 이미지의 코발트·페리윙클 블루 계열로 변경한다.
- 패널 본문은 밝은 쿨 화이트를 유지하고 경계선과 강조색만 새 팔레트로 통일한다.
- 링크, 열기/닫기 동작, 키보드 접근성, 외부 링크 주소는 변경하지 않는다.

### 3. `X개 조건 설정` 및 `AI 추천 시작하기`

- 선택 조건 요약 카드의 상단 배경과 카운트 강조색을 새 블루 팔레트로 변경한다.
- `AI 추천 시작하기` 버튼도 같은 계열의 선명한 블루로 변경한다.
- 버튼 글자 대비는 WCAG AA 수준을 목표로 한다.
- 선택 개수 계산, 버튼 활성화 조건, 추천 실행 동작은 변경하지 않는다.
- 칩 선택색, `STEP` 표기, 포커스 링도 동일한 팔레트로 자연스럽게 맞춘다.

### 4. 가장 하단 배너 및 푸터

- 기존 하단의 짙은 청록/남색 배경을 첨부 이미지와 조화되는 밝거나 중간 명도의 블루 계열로 변경한다.
- 푸터 문구는 현재 내용을 그대로 유지한다.
- 개인정보, 계정 삭제, 관리자 관련 링크와 버튼의 동작은 변경하지 않는다.
- 본문과 푸터가 구분되도록 얇은 블루 경계 또는 아주 약한 그라데이션을 사용한다.

### 5. 기타 색상 통일

- 상단 활성 메뉴, 선택 칩, 추천 결과 강조, 링크 호버, 포커스 링 등 기존 청록 강조색을 새 팔레트로 통일한다.
- 경고, 오류, 삭제 등 의미가 있는 빨간색과 성공 상태 색상은 의미 보존을 위해 무조건 블루로 바꾸지 않는다.
- 도서 표지, 상태 배지, 관리자 화면의 기능별 의미색은 가독성과 의미를 우선한다.
- 화면 전체를 한 가지 파란색으로 덮지 말고 쿨 화이트 표면과 네이비 텍스트를 충분히 사용한다.

## 배포

사용자 승인 후 아래 명령만 사용한다.

```powershell
npm run deploy
```

이 명령은 운영 랭킹을 배포 전후로 백업하고 보존 여부를 확인한다. 직접 `wrangler deploy`를 실행하지 않는다.

배포 후에는 운영 주소에서 HTML, CSS, 새 이미지 자산의 HTTP 200 응답을 확인하고, 랭킹 도서 수와 즐겨찾기 합계가 배포 전후 동일한지 보고한다.

- 모든 기존 기능과 데이터가 보존됨

- 사용자 승인 뒤 운영 배포 및 운영 화면 확인까지 완료됨
